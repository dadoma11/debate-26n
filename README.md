# Debate 26N · verificador independiente

Sitio estático para consultar afirmaciones del debate a cuatro del 26 de noviembre de 2026, con reproducción por marca temporal, filtros, contexto y enlaces a fuentes.

## Archivos

- `index.html`: estructura, metadatos y contenido editorial de método.
- `style.css`: diseño adaptable, estados accesibles y componentes visuales.
- `app.js`: reproductor, línea temporal, búsqueda y filtros.
- `claims.js`: afirmaciones, veredictos y catálogos de fuentes.

## Comprobación editorial

La fecha de corte de las fichas es el 27 de noviembre de 2026. Las cifras deben leerse con la fecha, población, definición y periodo de cada fuente. Las estadísticas oficiales son la referencia primaria; las verificaciones periodísticas aportan contraste y contexto. No se puntúan opiniones ni promesas.

Antes de publicar una actualización: confirmar la cita en el vídeo, abrir cada fuente primaria, comparar periodos y unidades, indicar cálculos propios, y mantener «Sin comprobar» cuando no haya evidencia suficiente. Los anuncios, contratos y viviendas del parque son magnitudes diferentes; tampoco deben mezclarse llegadas migratorias con saldo neto ni condenas con detenciones.

## Uso

Abre `index.html` en un navegador. El vídeo requiere conexión a YouTube. GitHub Pages publica directamente estos archivos estáticos desde la rama configurada.
